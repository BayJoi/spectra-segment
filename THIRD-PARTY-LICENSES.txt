LICENSE NOTE
------------

Spectra Segment's own source is under the GNU General Public License v3.0
(GPL-3.0-only).

However, the project depends on the `ultralytics` package, which is AGPL-3.0.
GPL-3.0 and AGPL-3.0 are *one-way* compatible: you may combine them, but the
combined work -- and therefore any binary or source you distribute -- must be
released under AGPL-3.0, and running it as a network service triggers AGPL-3.0
section 13. It is therefore inaccurate to describe the whole project as
GPL-3.0 once ultralytics is linked.

Consequences:
  * Distributing this software (with ultralytics) requires AGPL-3.0 compliance:
    publish the complete corresponding source under AGPL-3.0.
  * Commercial or closed-source distribution requires an Ultralytics Enterprise
    license, which removes the AGPL obligation for the ultralytics parts.
  * Personal, academic and fully open-source use is covered by AGPL-3.0 free of
    charge.

The project's own LICENSE file stays GPL-3.0 for the parts written here; the
AGPL-3.0 terms attach to the ultralytics dependency and anything statically or
dynamically combined with it.

Weights provenance
------------------

Every checkpoint the app downloads is fetched from a pinned URL and checked
against a sha256 digest before it is used. Provenance is not uniform, though:

  * Most files come from the `ultralytics/assets` v8.4.0 GitHub release, which is
    an official Ultralytics distribution.
  * `sam3.pt` comes from a community mirror and its digest could not be confirmed
    against any official source. Treat it as third-party.

Because the SAM 3 checkpoint and the ultralytics package are combined at runtime,
review both the Meta SAM License and the AGPL-3.0 obligation before distributing.
